- 本地仓库、已读上下文或用户给的材料能回答的不查网；要外部事实、版本、发布时间、价格或近期变更时才检索，同类信息合并成一次查询
- 路由：库/框架/SDK/CLI 的 API 与配置查 context7，公开 GitHub 仓库的架构与实现查 deepwiki，其余公开网页（新闻、对比、报错讨论）查 exa
- 进 codemode 先用 describeNamespace("mcp__<server>") 确认工具名与参数再调用，不凭名字猜
- deepwiki 只覆盖已索引的公开仓库，查不到就改为读本地代码或上游源码
- 优先一手来源（官方文档、release notes、上游仓库、规范）；二手来源只作补充，冲突时以更新、更权威者为准并说明分歧
- 搜索摘要只当线索，结论要用 fetch 类工具读出正文核对，不可仅凭摘要断言
- 引用只用于支撑事实性结论（纯常识或本机代码结论不附外链），格式 `来源：<标题> <URL>（<日期/版本>）`；找不到来源就说找不到，不伪造链接
- 检索词里不放密钥、私有代码与个人信息；同一 query 不原样重复发，没有结果就换表述、换语言、换源
- pi 已对 MCP 的网络错误与 408/429/5xx 自动重试两次；仍失败就换源或简化 query，再不行报告失败并标注不确定性，不要继续重发
- 外部信息与本机代码、仓库事实冲突时以本地为准，不用检索结果覆盖已确认的实现
